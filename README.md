# libinput-middle-scroll

Middle-button drag scrolling on Wayland, for compositors that don't expose
libinput's `ScrollMethod=button` (GNOME / Mutter).

X11 can do this in `xorg.conf`:

```
Option "ScrollMethod" "button"
Option "ScrollButton" "2"
```

This does the same on Wayland via an `LD_PRELOAD` hook.

## Install

```bash
sudo dnf install -y libinput-devel gcc
./install.sh
```

Log out and back in.

## How it works

`hook.c` overrides three libinput entry points:

- `libinput_device_get_name` — apply the configuration when the device is queried
- `libinput_device_config_scroll_set_method` — Mutter sets this afterwards, so force it back
- `libinput_device_config_scroll_set_button` — pin the button to `BTN_MIDDLE`

Devices that support two-finger scrolling are skipped, so touchpads keep their
normal behaviour.

`install.sh` writes the library into GNOME Shell's systemd drop-in:

```
~/.config/systemd/user/org.gnome.Shell@user.service.d/preload.conf
```

`LD_PRELOAD` in `environment.d` is filtered by systemd and has no effect here.

## Uninstall

```bash
rm ~/.config/systemd/user/org.gnome.Shell@user.service.d/preload.conf
systemctl --user daemon-reload
```

Log out and back in.
